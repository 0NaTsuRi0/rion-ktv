# 璃音K歌 (Rion KTV) 🎤🎶

> 专为家庭与聚会打造的轻量级全栈局域网 / 线上联动 KTV 点歌与播放系统。  
> 电视/投影仪沉浸式大屏播放，手机扫码免 App 即点即唱，支持全格式本地 MV 曲库与 B 站海量伴奏在线流媒体直点！

---

## 🌟 核心特性速览

- 📺 **TV / 大屏端沉浸播放**：自适应全屏视频输出、渐进式 HLS 转码、原唱/伴奏瞬间平滑切换、双声道伴奏剥离、当前/下首播放浮层通知。
- 📱 **手机端免安装点歌台**：局域网一键扫码访问，拼音首字母速搜、歌手聚类、点歌队列、一键置顶、即唱、收藏夹、常唱榜单。
- 🌐 **B 站全网在线点歌 (v0.2+)**：全站视频实时搜索、多分 P 合集智能解析过滤、MP4 流媒体实时 Range 零落地转发、封面防盗链穿透。
- 🎛️ **实时双向毫秒同步**：基于 WebSocket 状态广播，多设备音量同步、切歌、暂停/播放、原唱/伴唱状态毫秒级联动。
- 🛠️ **一体化曲库管理后台**：支持目录递归扫描、伴奏音轨探测、一键批量抓取网络高清封面、AI 伴奏分离集成、可选免密测试模式。
- 🚀 **极简部署与轻量化**：基于 Node.js + Express + SQLite (WASM)，纯本地持久化，无臃肿第三方外部依赖，开箱即用。

## 📖 版本自述与更新日志

### 📌 v0.2.3 (Current) & v0.2.0 系列
**全网流媒体在线点歌与体验进化版**

- 🚀 **B 站在线点歌体系**：
  - 接入最新 WBI 动态签名与 Nav 密钥自动缓存轮换机制，稳定检索全网视频。
  - 封装 `/stream/bilibili/:bvid/:cid` 实时管道，支持客户端 HTTP Range 分段请求，秒开播放与进度条随心拖拽。
- 📑 **多分 P 伴奏合集体验**：
  - 点歌时自动探测分 P 列表，单 P 视频一键秒点入队，多 P 视频唤起平滑弹窗并支持关键字快速检索。
  - 智能命名机制：多分 P 自动存储并展示为 `视频主标题 - 分P名`（如 `周杰伦伴奏合集 - P1. 晴天`），清晰直观。
- 🖼️ **封面防盗链与高可用中转**：
  - 全站配置 `no-referrer` 策略，解决移动端直接请求 CDN 导致的 `403 Forbidden`。
  - 新增 `/api/bilibili/cover` 后端代理路由，自带 Referer 伪装、移动端 UA 与 302 自动重定向处理，无缝降级到本地默认封面。
- 🔓 **管理后台免密模式**：
  - 新增 `ADMIN_AUTH=disabled` 支持，内测与家庭调试时无需反复输入密码，提升操作效率。

### 📌 v0.1.0
**独立局域网 KTV 基础架构重构版**

- 🏗️ **轻量全栈架构**：
  - 从原有复杂体系全面解耦，采用 Node.js + Express + SQL.js (WASM) 纯轻量化技术栈。
  - 启动秒开，本地数据目录独立隔离，彻底排除不必要的数据库与媒体文件污染 Git 追踪。

  - **TV 播放页** (`/tv`)：自动获取局域网 IPv4 并展示动态点歌二维码，支持遥控器播控适配。

## 🚀 快速启动指南

### 1. 环境准备
- **Node.js**: v18.0.0 或更高版本
- **FFmpeg**: 系统需安装 `ffmpeg` 并加入环境变量 PATH（或在配置中指定路径）

### 2. 安装与配置
克隆仓库并安装依赖：
```bash
git clone https://github.com/0NaTsuRi0/rion-ktv.git
cd rion-ktv
npm install
```

复制配置文件并按需修改：
```bash
cp .env.example .env
```

`.env` 常用参数说明：
```ini
# 服务端口
PORT=8080

# 歌曲视频目录（存放歌曲视频文件夹与独立伴奏）
MV_DIR=./mv

# 数据存储目录（存放 SQLite 数据库及 HLS 转码缓存）
DATA_DIR=./data

# 曲库管理端鉴权模式：enabled (需密码) 或 disabled (免密测试模式)
ADMIN_AUTH=enabled
```

### 3. 启动服务
- **Windows**: 双击运行 `start.bat` 或在终端执行：
  ```powershell
  npm start
  ```
- **Linux / macOS**:
  ```bash
  chmod +x start.sh
  ./start.sh
  ```

### 4. 访问端口与页面
- 📺 **电视 / 投影播放大屏**：`http://<局域网IP>:8080/tv`
- 📱 **手机扫码点歌台**：`http://<局域网IP>:8080/mobile`
- ⚙️ **曲库管理后台**：`http://<局域网IP>:8080/admin`

## 📁 目录结构说明

```text
rion-ktv/
├── server/               # 服务端核心逻辑
│   ├── index.js          # Express 主服务、WebSocket 服务及路由分发
│   ├── bilibili.js       # B站搜索、WBI 签名、流媒体与封面防盗链代理
│   ├── db.js             # SQLite 数据库初始化与操作封装
│   ├── hlsgen.js         # 渐进式 HLS 转码与切片调度
│   ├── scanner.js        # 本地曲库与伴奏文件扫描
│   ├── config.js         # 环境变量与运行时配置解析
│   └── cover-fetch.js    # 歌曲网络封面自动抓取
├── web/                  # 前端静态单页应用
│   ├── tv/               # 电视/大屏播放端
│   ├── mobile/           # 手机移动点歌端（含B站在线点歌）
│   ├── admin/            # 后台曲库管理与监控面板
│   └── icons/            # SVG 图标与默认封面资源
├── .env.example          # 环境配置示例模板
├── start.bat / start.sh  # 一键启动脚本
└── package.json          # 项目依赖与启动脚本定义
```
