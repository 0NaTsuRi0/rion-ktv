# 璃音 K 歌 · Rion KTV

璃音 K 歌是一套家庭和聚会用的局域网点歌系统。电脑运行服务，电视或投影打开大屏播放页，手机扫码点歌。曲库可以使用本地 MV、B 站视频和网易云音乐。

## 本地 KTV 功能

| 页面 | 已有功能 |
| --- | --- |
| 手机点歌 `/mobile/` | 按歌名搜索本地曲库，按歌手及其拼音首字母浏览，收藏喜欢的歌曲。可查看队列、置顶、即唱和移除歌曲。 |
| 大屏播放 `/tv/` | 全屏播放和扫码点歌。左上角轮换显示当前与下一首，底部显示进度。手机遥控可调音量、暂停、重唱、切歌及切换原唱和伴奏。 |
| 曲库管理 `/admin/` | 递归扫描或上传本地 MV，编辑歌名和歌手，单首或批量补全封面。可上传独立伴奏，配置 Pymss 后也可以批量分离人声、生成伴奏。 |

本地曲库支持 MP4、MKV、AVI、FLV、MOV、WebM 和 MPG。文件可以命名为 `歌手 - 歌名.mp4`。扫描时，服务会读取视频时长和音轨信息，并识别同目录下名称含 `_伴奏` 或 `accompaniment` 的伴奏文件。可将 `cover.jpg` 放在歌曲目录中作为封面。

本地视频由 FFmpeg 按需生成 HLS 切片。内置双音轨或带独立伴奏文件的歌曲可以在播放中切换原唱和伴奏。手机和 TV 通过 WebSocket 同步队列及播控状态。曲库、收藏和播放历史保存在本地 SQLite，待播队列会在服务重启时清空。

## v0.20.1

- **网易云点歌**：在手机端搜索歌名或歌手。只有网易云返回完整音源时才允许入队。可选配置自己的网易云登录态来使用账号已有的播放权限。
- **TV 双行歌词**：网易云歌曲显示方形封面和模糊封面背景。两行歌词交替预告，当前句用封面色高亮并稍微放大。左上角轮换显示播放中和下一首。
- **B 站链接点歌**：原搜索栏同时支持关键词、BV 号、视频长链接和手机分享的 `b23.tv` 短链接。链接带 `?p=3` 时，点歌会选择第 3 P。

## 安装和启动

准备 Node.js 24、FFmpeg 和 FFprobe。将 FFmpeg 和 FFprobe 加入 PATH，也可以在 `.env` 为它们设置完整路径。

```shell
git clone https://github.com/0NaTsuRi0/rion-ktv.git
cd rion-ktv
npm install
npm start
```

首次启动时，服务会根据 `.env.example` 创建 `.env`。需要调整曲库路径或端口时，改完 `.env` 再重启。Windows 也可以用 `start.bat` 启动。

| 页面 | 地址 | 功能 |
| --- | --- | --- |
| 大屏 | `http://<服务器局域网 IP>:8080/tv/` | 播放、显示点歌二维码和当前／下一首 |
| 手机 | `http://<服务器局域网 IP>:8080/mobile/` | 搜歌、点歌、管理队列和远程播控 |
| 管理 | `http://<服务器局域网 IP>:8080/admin/` | 扫描本地曲库、编辑曲目和管理封面 |

电脑自己访问时，可以把服务器 IP 换成 `localhost`。手机和大屏所在设备需要能访问服务器。首次打开大屏，点一下画面即可启用音频。

## 添加歌曲

- **本地 MV**：把视频放进 `songs/` 或 `MV_DIR` 指定的目录，再到管理页扫描。双音轨或已有独立伴奏的歌曲可以切换原唱和伴奏。
- **B 站**：在手机端打开「B站」标签，输入关键词、BV 号或分享链接。搜到视频后点「＋」。多分 P 视频可以选择具体分 P。
- **网易云**：在手机端打开「网易云」标签，搜索并点「＋」。TV 会拉取对应的 LRC 歌词。按 `L` 可显示或隐藏歌词。网易云音源为单音轨。

## 配置

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `PORT` | `8080` | 服务端口 |
| `MV_DIR` | `./songs` | 本地 MV 目录 |
| `DATA_DIR` | `./data` | 数据库目录 |
| `HLS_DIR` | `./data/hls` | HLS 切片缓存 |
| `WATCH_ENABLED` | `true` | 监控本地曲库变化并触发扫描 |
| `FFMPEG_PATH`、`FFPROBE_PATH` | 通过 PATH 查找 | 指定媒体工具的完整路径 |
| `PYMSS_PYTHON`、`PYMSS_SRC` | 见配置示例 | 可选的 Pymss Python 可执行文件及源码目录，用于生成伴奏 |
| `ADMIN_AUTH` | `true` | 启用曲库后台密码保护 |
| `BILI_COOKIE` | 空 | 可选的 B 站登录态 |
| `NETEASE_MUSIC_U` | 空 | 可选的网易云登录态，只填自己账号 Cookie 中 `MUSIC_U` 的值 |

播放权限以平台对当前账号和歌曲的实际返回为准。网易云登录值直接填写在本机 `.env`，去掉引号和 `MUSIC_U=` 前缀。凭证只保存在服务端。数据库、曲库媒体、转码缓存和本机 `.env` 都在 Git 忽略范围内。

## 项目结构

- `server/`：Express API、WebSocket、SQLite 曲库、流媒体和歌词。
- `web/tv/`、`web/mobile/`、`web/admin/`：大屏、手机点歌台和曲库后台。
- `songs/`、`data/`：本地曲库和运行数据。
